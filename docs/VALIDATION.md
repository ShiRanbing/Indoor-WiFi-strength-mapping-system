**核验日期：2026 年 11 月 5 日。** 本页记录仓库整理过程中的软件检查，与 2025 年论文实验区分。

## 环境

- Windows，Python 3.9.5。
- NumPy 2.0.2、Pandas 2.2.3、Matplotlib 3.9.4、SciPy 1.13.1。
- PyQt5 5.15.11、openpyxl 3.1.5、pyserial 3.5。
- Qt 使用 `offscreen` 模式执行绘图和文件导入 / 导出流程；没有打开可见窗口或连接串口。

## 检查内容

| 范围 | 验证方法 |
| --- | --- |
| 论文矩阵 | 对照图 20 与图 30 人工核对 30 个值；检查 5 × 6 形状、标签顺序和数值范围 |
| CSV 导入 | 通过桌面程序的文件导入方法加载 `examples/report_grid.csv` |
| Excel 导入 | 将同一矩阵写入临时 `.xlsx`，通过同一方法重新读取并比较数值 |
| 两种绘图 | 分别执行原始和 cubic 绘图；核对 5 × 6 / 100 × 100 输出及数值有限性 |
| 数值与色条 | 原始图包含 30 个标签；切换图像后保持单个主图和单个色条 |
| PNG / JPG 导出 | 通过原程序的导出方法生成图片，并重新打开验证文件完整性 |
| 串口解析 | 验证 `RAW`、`AVG`，以及状态文字、非法数值、字段不足的跳过行为 |
| Python 源码 | 对四个 `.py` 文件执行语法解析；不运行包含旧路径的两个早期脚本 |
| 配套驱动 | 逐字节比对 5 个驱动 / 字库文件与本地工程原件 |
| 文档 | 检查仓库内 Markdown 链接、图片引用及图片可读性 |

这些检查均已通过。它们验证示例使用路径和整理内容，不代表已经建立完整的自动化测试套件。
